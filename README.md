# Welcome to git work branch
The goal of this project is to abstract away git worktrees and provide a DWIM (Do what I mean) branch-oriented experience that abstracts away worktrees.

## Prerequisites
- [fzf](https://github.com/junegunn/fzf)
- [zoxide](https://github.com/ajeetdsouza/zoxide)

## Similar projects
[worktrunk](https://github.com/max-sixty/worktrunk) - Helps with worktrees, many more feature but less DWIM in nature. You still need to manage worktrees.

## Status
- Tested on gnu coreutils on linux (mac/bsd users may have compatibility issues with default utils)
